# Guitar Effects Vault

A public, open-source website collecting **guitar effects settings**, **tabs**, and **backing tracks** for famous artists and albums.

Live site: [https://aross197.github.io/guitar-effects-vault](https://aross197.github.io/guitar-effects-vault)

## Features

- **Artist & Album Database** – Detailed amp + pedal settings for classic tones
- **Tabs** – Simple text tabs for key riffs
- **Record Button** – Record yourself in the browser (Web Audio / MediaRecorder)
- **Backing Tracks** – Practice along (placeholder tracks + free sources)
- Search, filter by artist / genre / decade
- Fully static – runs on GitHub Pages

## How to contribute

1. Fork the repo
2. Add new entries to `data/effects.json`
3. Open a Pull Request

## Tech

- Vanilla HTML / CSS / JS
- Web Audio API + MediaRecorder for recording
- No build step required
